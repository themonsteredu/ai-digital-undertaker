# 디지털 장의사 홍보영상

- `ai-digital-undertaker-promo.mp4` — 1920×1080, 30fps, 약 55초, 배경음악 + 하단 자막 포함 (약 14MB)
- `ai-digital-undertaker-promo.srt` — 자막 파일 (유튜브 등에 따로 올릴 때 사용)
- `source/` — 다시 만들 때 쓰는 녹화·편집 스크립트 (앱 배포에는 포함되지 않음)

## 영상에 나오는 장면
실제 앱 화면을 컴퓨터 안에서만(로컬 개발 모드의 화면 검수용 `/qa` 가상 데이터) 녹화했습니다. 실제 수업 서버나 학생 기록은 전혀 사용하지 않았습니다.

1. 오프닝 — "오늘, 우리 반이 디지털 장의사가 됩니다"
2. 네 명의 의뢰인과 네 가지 사건 (택배 상자·SNS 사진·옛날 계정·단톡방)
3. 송장과 영수증에서 개인정보를 직접 드래그해 표시하고 확인
4. 교실 사진 속 명찰·칠판·학생증 찾기
5. 처리 방법 판단 — 틀리면 다시 생각할 관점을 안내
6. 중등 심화 — 근거 자료 + 결론 + 이유 연결
7. 사건 4개와 보고서·반 평균·약속 카드·가림 도장 요약
8. 나의 약속 카드 쓰기와 가림 도장 설계
9. 교사 화면 (학생 현황·선택과 발견·약속 카드·수업 슬라이드)
10. 마무리 — 앱 이름과 한 줄 메시지 (배포 주소는 저장소에서 확인되지 않아 넣지 않았습니다)

## 다시 만들 때 (개발자용 메모)
`source/` 파일을 작업 폴더에 복사한 뒤 `pnpm dev`로 앱을 켜고, `node go.mjs intro|choice|finish|teacher`, `DPR=2 node go.mjs scan|photo|inquiry`로 녹화 → 각 `clips/*.mp4`를 `frames/<이름>/%05d.jpg`로 풀기 → `public/art/slide-01.png`를 `hero.png`로 복사 → `python3 music.py` → `node render.mjs full` → ffmpeg로 `out/` 이미지와 `music.wav`를 합칩니다.
